# Portfólio pessoal

Projeto desenvolvido para a Atividade Prática 2 da disciplina GAC116 - Programação Web.

## Versões

- `bootstrap/index.html`: interface usando Bootstrap 5.
- `bulma/index.html`: interface equivalente usando Bulma.

As duas páginas possuem o mesmo conteúdo, responsividade e alternância entre tema claro e escuro. Abra `index.html` para escolher uma versão.
